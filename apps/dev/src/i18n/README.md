# Translations

ograf.dev ships in English (root), Brazilian Portuguese (`/pt`) and European
Spanish (`/es`). English is the source; the other two must never lag it.

## Where text lives

| What | Where | Enforced by |
| --- | --- | --- |
| Shared chrome (nav, footer, "Loading…") | `i18n/messages/{en,pt,es}.ts` → `useT()` | `Messages` type |
| Page titles and descriptions | `i18n/meta.json` → `useRouteMeta()` and the prerender | prerender throws on a missing entry |
| Page and component prose | `i18n/copy/<name>/{en,pt,es}.tsx` → `useCopy(X_COPY)` | `pt: XCopy` type annotation |
| JSON content | `content/<name>.json` + `content/i18n/{pt,es}/<name>.json` → `content/localized/<name>.ts` | `scripts/check-i18n.mjs` (prebuild) |

### Page copy

`i18n/copy/about/` is the reference:

- `en.tsx` exports `const en = { … }` and `export type AboutCopy = typeof en`.
- `pt.tsx` / `es.tsx` export `const pt: AboutCopy = { … }` — a missing or extra
  key is a type error.
- `index.ts` exports `ABOUT_COPY: Readonly<Record<Locale, AboutCopy>>`.
- Values may be strings, arrays/objects of strings, JSX fragments (inline
  `<code>`, `<strong>`, links), or functions for interpolation
  (`(n: number) => \`${n} rules\``). Class names repeated across the three
  files go in a sibling `styles.ts`.
- Internal links inside copy use `Link` from `i18n/Link` with unprefixed paths
  (`to="/spec"`); it adds `/pt` or `/es`. Never hard-code a locale prefix.
- The page keeps all layout and Tailwind classes; only text moves out.

### JSON content

Copy `content/foo.json` to `content/i18n/pt/foo.json` and `…/es/foo.json`,
translate the strings, and load all three through `content/localized/foo.ts`
(see `localized/faq.ts`). The check script requires identical keys, array
lengths, numbers and booleans, and identical values for identifier-like keys
(`id`, `slug`, `url`, `logo`, `date`, …). Consumers call `useCopy(FOO)`.

## What is not translated

- Code: code blocks, identifiers, method and field names, file names, JSON
  keys, CSS classes. Tutorials excerpt the real template files, which stay
  English.
- Proper names: OGraf, EBU (keep the acronym; the full name may be translated),
  product and company names, GDD type names, spec terms used as identifiers
  (`stepCount`, `customAction`, `playAction`, `skipAnimation`, `renderType`).
- Quotes and titles of external sources: GitHub issue/PR titles and comments,
  article and talk titles, video titles. Our own summaries of them are
  translated.
- Package Checker findings (rule titles and messages in a report). They are
  generated by the validator like compiler output. The checker UI around them
  is translated.
- Demo data inside templates and zips.

## Voice

- **pt-BR:** "você", direct and friendly, Brazilian spelling and vocabulary
  ("arquivo", "tela", "celular", "time" for a sports team). Avoid Portugal-only
  forms.
- **es-ES:** "tú" for the reader, "vosotros" for plural address, Spain
  vocabulary ("ordenador", "vídeo", "archivo", "móvil", "equipo"). No voseo.
- Keep sentence length and tone of the English. Don't add or drop claims.
  Keep numbers, units and durations exactly (`600 ms`, `1920×1080`).
- Headings end with a period where the English one does.
